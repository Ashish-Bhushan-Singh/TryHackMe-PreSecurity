## 🧠 Understanding the Basics

### 1. What is Offensive Security?

Offensive security is about testing computer systems, networks and applications by using techniques that attackers might use.

The purpose is to find security weaknesses before real attackers can take advantage of them.

These tests are performed with proper permission and within an authorised environment.

Professionals working in this area often take part in penetration testing and Red Team activities.

### 2. Why Do We Use Virtual Machines?

A virtual machine (VM) allows us to run another operating system inside our existing computer.

For example, we can run Kali Linux on a Windows computer without replacing Windows.

Virtual machines are useful because they allow us to:

- Practise security techniques in a separate environment.
- Test tools without directly changing our main operating system.
- Experiment with different operating systems.
- Restore a previous state when something goes wrong.

This makes them useful for cybersecurity labs and practical training.

### 3. Getting Familiar with Gobuster

Gobuster is a command-line tool commonly used during website enumeration.

It checks possible paths using a wordlist to discover content that may not be visible through normal website navigation.

Depending on the mode being used, Gobuster can help discover:

- Website directories.
- Files and web pages.
- Subdomains.
- Virtual hosts.

In this exercise, I used its directory enumeration feature to look for hidden pages on a website.

### 4. What is Directory Enumeration?

Directory enumeration is the process of checking a website for available directories and files.

Some websites contain pages that are not linked from their homepage. Enumeration helps security testers identify these locations.

For example:

```text
/admin
/backup
/images
/bank-transfer
```

Finding a directory does not automatically mean it is vulnerable. It simply gives us another location to investigate.

### Task 2 – Searching for Hidden Website Directories

For the practical exercise, I used Gobuster against the FakeBank website provided by TryHackMe.

The objective was to discover website paths that were not immediately visible.

**Command used:**

```bash
gobuster -u http://fakebank.thm -w wordlist.txt dir
```

**Understanding the command:**

| Option | Purpose |
|---|---|
| `gobuster` | Starts the Gobuster tool |
| `-u` | Sets the target website |
| `http://fakebank.thm` | Website being tested |
| `-w` | Specifies the wordlist |
| `wordlist.txt` | Contains possible directory names |
| `dir` | Selects directory enumeration mode |

<image-placeholder></image-placeholder>

**Important results:**

```text
/images          (Status: 301)
/bank-transfer   (Status: 200)
```

The results showed two interesting paths.

- **200 OK:** The requested page was found successfully.
- **301 Moved Permanently:** The requested location redirects to another URL.

The `/bank-transfer` path returned a successful response, so I investigated it further.

**Discovered page:**

```text
http://fakebank.thm/bank-transfer
```

## 📝 Important Things to Remember

1. Offensive security helps organisations find weaknesses before attackers do.
2. Virtual machines provide a separate environment for practical security training.
3. Gobuster can help discover website directories and files.
4. Wordlists contain possible names that enumeration tools test against a target.
5. HTTP response codes help us understand how a web server responds.
6. Discovering a hidden page is only the beginning; the page must be investigated further.
