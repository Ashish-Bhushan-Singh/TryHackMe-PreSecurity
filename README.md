

# 🛡️ Cyber Security 101 – TryHackMe Learning Path

This repository contains my notes and practical work while learning cybersecurity through the **TryHackMe-PreSecurity**.

I created this repository to document what I learn, the commands I use, the tools I explore, and the challenges I solve along the way. It serves as a personal reference that I can revisit whenever I need to revise a concept or practice a technique.

Rather than keeping everything in one place, I've organised the documentation module by module and room by room.

---

## 📖 About This Repository

The TryHackMe Cyber Security 101 path covers several important areas of cybersecurity, starting with fundamental concepts and gradually introducing practical security tools and techniques.

This repository includes:

- Notes from all 14 learning modules.
- Room-by-room explanations and walkthroughs.
- Commands and tools used during practical exercises.
- Screenshots and relevant evidence.
- Important concepts and technical observations.
- Key takeaways for future revision.

My aim is to build a solid understanding of cybersecurity fundamentals while keeping a record of my learning progress.

- **Practical Steps:** How I approached and completed the tasks.

## 📝 How I Document Each Room

To keep the notes consistent and easy to follow, I'll generally use the following structure:

1. **Introduction:** What the room is about.
2. **Concepts:** Important explanations and terminology.
3. **Commands & Tools:** Commands, options and tools used.
4. **Practical Walkthrough:** Steps followed during the exercises.
5. **Observations:** Results and findings from the lab.
6. **Key Takeaways:** What I learned and what I want to remember.

The focus is on documenting the actual learning process rather than simply collecting answers.
